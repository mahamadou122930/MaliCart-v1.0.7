# MaliCart — AI Agent Instructions

MaliCart is a **Symfony 7 / PHP 8.2** e-commerce application backed by **PostgreSQL 16** and served via **Webpack Encore + Symfony Asset Mapper**. The admin panel uses **EasyAdmin 4**.

---

## Quick Commands

```bash
# Assets
npm run dev          # one-shot dev build
npm run watch        # watch mode
npm run build        # production build

# Database
php bin/console doctrine:migrations:migrate
php bin/console doctrine:migrations:generate   # after entity changes

# Tests
php bin/phpunit                    # all tests
php bin/phpunit tests/Foo.php      # specific file

# Cache
php bin/console cache:clear
```

> **Docker**: run `docker compose up -d` to start the PostgreSQL 16 container (see [compose.yaml](compose.yaml)). The connection URL is `postgresql://app:!ChangeMe!@localhost:5432/app`.

## Architecture

```
Controller → Form → Service/Manager → Repository → Entity → Database
```

| Layer | Path | Notes |
|---|---|---|
| Controllers | `src/Controller/` | Public; `src/Controller/Admin/` for EasyAdmin CRUDs |
| Forms | `src/Form/` | Bootstrap 5 layout (configured in `config/packages/twig.yaml`) |
| Services | `src/Service/` | Business logic (cart, orders, promotions) |
| Managers | `src/Manager/` | Thin wrappers / state helpers |
| Entities | `src/Entity/` | Doctrine ORM, **PHP 8 attributes** only — no XML/YAML mapping |
| Repositories | `src/Repository/` | Extend `ServiceEntityRepository<Entity>` |
| Templates | `templates/` | Twig; one subdirectory per controller domain |

## Routing Conventions

- **Strategy**: Attribute-based (`#[Route(...)]`), declared on controller methods.
- **Naming**: `<domain>.<action>` — e.g., `cart.index`, `account.info`, `order.checkout`.
- **Admin**: routes are auto-generated by EasyAdmin from `DashboardController` and CRUD controllers under `src/Controller/Admin/`.

```php
#[Route('/cart', name: 'cart.index')]
public function index(): Response { ... }
```

## Entities & Key Facts

All entities live in `src/Entity/` and use **Doctrine PHP 8 attributes**.

| Entity | PK type | Key fields / relations |
|---|---|---|
| `User` | UUID (`Symfony\Uid\Uuid`) | `email` (unique), `roles` (JSON), `password`, `firstname`, `lastname`, `phoneNumber`, `avatar` (DiceBear URL auto-set on create); 1:N → Address, 1:N → Order |
| `Address` | INT auto | `name` (label), `firstname`, `lastname`, `address`, `postal`, `city`, `country`, `phone`, `isPrimary`; N:1 → User |
| `ShopProduct` | INT auto | `name`, `subtitle`, `description`, `price` (**in cents**), `slug` (unique, `[a-z0-9-]+`), `illustration`×4, `statut` (bool); N:1 → SubCategory; N:1 → Brand; M:N → Color, Size |
| `ShopProductCategory` | INT auto | `name`; M:N ↔ SubCategory |
| `ShopProductSubCategory` | INT auto | `name`; M:N ↔ Category; 1:N → ShopProduct |
| `ShopProductBrand` | INT auto | `name`; 1:N → ShopProduct |
| `ShopProductColor` | INT auto | `name`, `code` (hex) |
| `ShopProductSize` | INT auto | `name` (e.g., "S", "M", "XL") |
| `Order` | INT auto | `reference` (unique, `dmYuniqid()` format), `status` (`'cart'` while in checkout), `isPaid` (bool), `state` (int), `carrierName`, `carrierPrice`, `delivery` (TEXT), `discount`; N:1 → User; 1:N → OrderDetails |
| `OrderDetails` | INT auto | `product` (name string — **not a FK**), `quantity`, `price`, `total`, `size`, `color`; N:1 → Order |
| `Carrier` | INT auto | `name`, `description`, `price`, `deliveryTime` |

> **Price convention**: `ShopProduct.price` is stored as **integer cents** (e.g., `4999` = €49.99). `OrderDetails.price` and `total` are `DOUBLE`.

## Security

- **Authenticator**: `src/Security/LoginFormAuthenticator.php` (extends `AbstractLoginFormAuthenticator`)
- **Login route**: `/connexion` (`index.login`); logout: `/logout` (`app_logout`)
- **On success**: redirects to previous target or `account.info`
- **Access control**: `/account/*` and `/order/*` require `ROLE_USER`
- **Password hashing**: `auto` (bcrypt)
- **Remember-me**: 7 days
- No custom voters — standard Symfony role checks only

---

## Cart

The cart is **session-based**, stored under the key `'panier'`.

- `src/Service/CartManager.php` — `getCart()` / `setCart()`
- `src/Manager/CartManager.php` — thin wrapper (same responsibilities)
- Cart items are plain arrays, **not** persisted until `OrderService::createOrder()` is called.

## Common Pitfalls

- `ShopProduct.price` is **cents** (int) — don't store decimals directly.
- `OrderDetails.product` stores the **product name as a string**, not a foreign key — snapshot at order time.
- The `User.avatar` is auto-set from the **DiceBear API** in a lifecycle callback on first persist — don't overwrite it manually.
- `Order.status` starts as `'cart'` (constant `Order::STATUS_CART`) and transitions through checkout; `isPaid` flips only after payment confirmation.
- Cart session key is `'panier'` (French) — used in `CartManager`.
